# 國立雲林科技大學 3D 無人機瀏覽

以無人機視角飛行瀏覽雲科大校園的 3D 場景。單一靜態網頁，直接在瀏覽器執行。

## 操作

- WASD 移動，Space 上升，C 下降，Shift 加速
- 點一下畫面後移動滑鼠轉動視角（Esc 釋放），滾輪調整速度
- 數字鍵 1 到 6 切換視角，T 建築標籤，N 切換正午、黃昏、夜景，O 自動環繞，H 隱藏說明

## 資料與限制

- 建築、道路、水域、綠地來自 OpenStreetMap（ODbL），© OpenStreetMap contributors。
- 樓高依校方總務處公告的樓層數估算（樓層數 x 層高），不是實測；OSM 沒有樓層資料的建築為推估。
- 路易莎咖啡的位置依校方餐飲頁描述推定，非實測。
- 校門廣場、校名塔等依街景照片重建為簡化模型，不是照片級實景。
- 需要支援 WebGL 的瀏覽器與一般顯示卡。

由 Claude Code 的 `campus-3d-drone` 技能生成。
